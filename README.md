# Viral Lifecycle BNGL Model

BioNetGen implementation of the viral lifecycle model from the integrated virus-immune model.

## Quick Start

```bash
# Install dependencies
pip install bionetgen libroadrunner pandas matplotlib numpy openpyxl

# Run BNGL simulation
python simulate_viral_lifecycle.py

# (Optional) Run MATLAB validation
matlab -batch "run_viral_lifecycle_matlab"

# (Optional) Compare results
python validate_viral_lifecycle.py
```

See **[QUICKSTART.md](QUICKSTART.md)** for detailed step-by-step instructions.

## Model Overview

The viral lifecycle model captures:
- Virus entry and internalization (V_0 → V_I → R_cyt)
- Protein translation (R_cyt → P_S, P_NS)
- Replication complex formation (R_cyt + P_NS → RC_CM)
- RNA replication (RC_CM → R_CM + R_ds)
- Virus assembly and release (P_S + R_cyt → V_E)

## Model Parameters

All parameters are extracted from `../Param.xlsx`. Key parameters:

- `k_en = 2.00e-03` - Virus entry rate (1/min)
- `k_f = 5.17e-04` - Viral fusion rate (1/min)
- `k_a = 6.00e-07` - Virus assembly rate (1/mol·min)
- `k_t = 3.95e-01` - Translation rate (1/min)
- `tau = 3.48e+02` - Membrane formation time constant (min)

## Initial Conditions

- V_0 = 100 (MOI = 10, matching line 106 of RunThis.m)
- All other species = 0

## Simulation Settings

- **Duration**: 48 hours (2880 minutes)
- **Time points**: 200
- **Method**: ODE (deterministic)
